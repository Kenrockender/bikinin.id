FAQ

Pertanyaan yang sering muncul.

Berapa lama pengerjaannya? +

Landing page sekitar 1 minggu, website bisnis lengkap 2 sampai 3 minggu, app custom disesuaikan lagi sama scope fiturnya.

DP dulu buat mulai kerja, sisanya dibayar setelah selesai dan sebelum serah terima file.

Boleh revisi berapa kali? +

2 kali revisi udah termasuk di harga paket. Revisi tambahan di luar itu dihitung terpisah.

Sepenuhnya punya kamu. Source code dan akses domain diserahkan setelah pembayaran lunas.

Kalau butuh perbaikan setelah selesai gimana? +

Ada paket maintenance bulanan buat update dan perbaikan, tinggal ngobrolin pas konsultasi.
